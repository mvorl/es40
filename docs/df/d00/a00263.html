◆ zext_u64_8()

u64 zext_u64_8 ( u64 a)
inline

Zero-extend an 8-bit value to 64 bits (LDBU).

Masks off everything above the byte so that an MMIO device read wider than the access size is narrowed to the architected byte (HRM: LDBU is "Load zero-extended byte"). DRAM byte reads are already <= 0xff, so this is a no-op there.
