◆ main()

int main ( int argc,
char * argv[] )

Entry point for the application.

Does the following:

  • Try to find the configuration file.
  • Reads the configuration file, and uses the configurator to instantiate all system components.
  • Creates the trace-engine if in debug mode.
  • Runs the emulator.
  • Cleans up.
