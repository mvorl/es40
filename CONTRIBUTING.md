# Contributing to ES40  
  
ES40 as a whole is distributed under the GNU General Public License,  
version 2, due to historical GPL-2 code usage and requirements.  
  
It this fork's preference that any newly created files/devices or entirely   
rewritten ones be licensed under BSD-1-Clause to allow for permissive usage  
in advancing other emulation projects.  
  
- **New files:** The preference here would be BSD-1-Clause, an example header  
  is used in `src/i2c_spd.cpp`, with your own copyright line.  
  The license in a file's header is the one that applies to that file's code.  
- **Changes to existing files** are contributed under that file's license,  
  as stated in its header.  
- **Please avoid making a permissively licensed file more restrictive**, for  
  example by adding GPL code to a BSD-licensed file, where possible.  
- **Code from other projects** is welcome under a GPL-2.0-compatible  
  license; please keep its original copyright and license notices.
